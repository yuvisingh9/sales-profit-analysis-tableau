# Data Visualisation Internship Project

## Overview
This repository contains my Data Visualisation Internship project, focused on analysing sales data and presenting meaningful insights through an interactive dashboard.

## Objectives
- Analyse sales data to identify trends and patterns.
- Present key performance indicators (KPIs) using visualisations.
- Understand sales performance and business insights.
- Develop data analysis and visualisation skills.

## Tools Used
- Microsoft Excel
- Data Visualisation and Dashboard Design
- GitHub for project documentation

## Project Deliverables
- Sales dashboard
- Dashboard screenshots
- Key observations and insights
- Final PDF report

## Key Observations
The dashboard helps identify sales trends, compare performance across categories, and understand overall business performance. The visualisations make the data easier to interpret and support data-driven decision-making.

## Project Files
- `screenshots/` — Dashboard screenshots
- `Data_Visualisation_Report.pdf` — Final project report
- `observations.md` — Key findings and observations

## Learning Outcomes
- Understanding data visualisation techniques
- Creating dashboards and presenting KPIs
- Interpreting sales data
- Documenting and publishing project work using GitHub
